## Project Description

This project is a Course Catalog application built with Next.js, TypeScript and Tailwind CSS. It includes static and dynamic routing, reusable components, responsive layouts and UI improvements from Lab 1 and Lab 2.

## Lab 1

- Next.js 16 App Router
- TypeScript
- Tailwind CSS
- Static routes: `/`, `/about`, `/courses`
- Dynamic route: `/courses/[id]`
- `generateStaticParams`
- Server Components by default
- Client Component: `LikeButton`
- `loading.tsx` and `not-found.tsx`
- Mock course data with simulated delay

## Lab 2

- Added reusable shadcn/ui-style `Card` and `Button` components
- Updated `CourseCard` using reusable UI components
- Added responsive course grid
- Added card hover effects
- Improved responsive navigation
- Kept `CourseCard` as a Server Component

## Launch Instructions

1. Clone the repository:

```bash
git clone https://github.com/SarkytkaliDias/Course-catalog.git
```

2. Open the project folder:

```bash
cd Course-catalog
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open in the browser:

```text
http://localhost:3000
```

## Build Check

Before submission, run:

```bash
npm run build
```
